# Docs for AI agents and the bundled skill

This page owns the docs that teach AI agents to write Wvlet: the `for-ai-agents` website page and the bundled Agent Skill. Why the skill ships with the compiler is in [the bundled skill ADR](../adr/2026-11-22-bundled-agent-skill.md).

**When a PR changes query syntax, operators, CLI commands, or options, update both `website/docs/for-ai-agents.md` and the skill in `plugins/wvlet/skills/wvlet/` in the same PR.**

## The for-ai-agents page

- `website/docs/for-ai-agents.md` is the entry point for agents writing Wvlet: cheat sheet, SQL mapping table, and common mistakes.
- Verify every syntax example against the compiler (`wvlet run` / `wvlet compile`), not from memory.
- `llms.txt`, `llms-full.txt`, and the per-page `.md` copies are generated by `docusaurus-plugin-llms` at build time (see `website/docusaurus.config.ts`); never edit or commit them.
- Give new doc pages a `description` in their frontmatter, and open each page with a one-paragraph answer to "what is this and when do I use it".

## The bundled skill

- `plugins/wvlet/skills/wvlet/` is listed by `.claude-plugin/marketplace.json` (install with `/plugin marketplace add wvlet/wvlet`).
- It is also embedded in every CLI: `skillGen` in build.sbt generates `wvlet.lang.skill.BundledSkill`, served by `wvlet skill` (`install --agent claude|codex|pi`, `list`, `remove`, following the `tdx skill` layout).
- `plugin.json` has no `version` on purpose: installed copies track commits, so there is nothing to bump.
- Validate the manifests with `claude plugin validate .` and `claude plugin validate plugins/wvlet`.

## Gates

- `./sbt "runnerJVM/testOnly *SkillSnippetTest"` checks every `wvlet` fence in the skill and in `for-ai-agents.md`. The fence info string picks the check:
  - `` ```wvlet `` parses only (snippets that read tables that don't exist).
  - `` ```wvlet run `` compiles and runs on DuckDB, and its `test` lines must pass. Prefer this, with inline `val t(...) = [[...]]` tables.
  - `` ```wvlet skip `` marks fragments that are not complete statements.
- `./sbt "langJVM/testOnly *SkillFreshnessTest"` fails when a keyword in `WvletToken` appears in no code example of the skill. Add an example, or list the keyword in `SkillFreshnessTest.notInSkill` with a reason.
- The reserved-keyword list in `references/syntax.md` is generated: `./sbt "langJVM/Test/runMain wvlet.lang.compiler.parser.SkillKeywordGenerator"`.
